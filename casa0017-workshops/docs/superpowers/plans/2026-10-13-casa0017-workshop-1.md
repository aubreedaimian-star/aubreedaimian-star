# CASA0017 Workshop 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive, accessible four-page personal website that completes CASA0017 Workshop 1.

**Architecture:** Four static HTML pages share one stylesheet and a progressive-enhancement script. A small Node test suite checks document structure, navigation, local assets, and accessibility-critical markup without introducing a frontend framework.

**Tech Stack:** HTML5, CSS3, vanilla JavaScript, SVG, Node.js built-in test runner

**Spec:** `docs/superpowers/specs/2026-10-13-casa0017-workshops-1-3-design.md`

## Global Constraints

- Use plain HTML, CSS, and JavaScript with no build step.
- Use real, editable content for Aubree Dai without inventing private details, preferences, or precise location data.
- Meet WCAG 2.1 AA basics and support 320, 768, 1024, and 1440 pixel viewports.
- Keep all Workshop 1 assets inside `workshop-1/`.
- Add the repository-level GenAI acknowledgement required by the design spec.

## Review Focus

- A page opened from any route must have working relative navigation to all four pages.
- The mobile menu must remain usable with JavaScript disabled and expose its state accessibly when enhanced.
- Keyboard focus must be visible on every interactive control.
- Long headings and paragraphs must wrap without horizontal overflow at 320 pixels.
- The original SVG illustration must have useful alternative text and no external asset dependency.
