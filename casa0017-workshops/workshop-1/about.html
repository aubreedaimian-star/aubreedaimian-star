About

Curious about the space between data and daily life.

I’m developing a practical understanding of web architecture: how content, presentation, behaviour, and networked services work together in the browser.

What I’m learning

Building from first principles

CASA0017 begins with the fundamentals—semantic HTML and maintainable CSS—before moving into JavaScript, APIs, mapping, and live data. I’m using each workshop to understand not only what the code does, but why the web platform behaves that way.

My aim is to create interfaces that make complex urban and spatial information easier to explore. That means paying attention to accessibility, clear language, performance, and the context in which a person meets the data.

Working principles

A small checklist for every page

  • Start with meaning.Use the right HTML before adding decoration.
  • Design for different people.Keyboard, screen size, and assistive technology should not be afterthoughts.
  • Make states visible.Loading, success, empty, and error states all need useful feedback.
  • Keep learning inspectable.Readable source and documentation make progress easier to revisit.
