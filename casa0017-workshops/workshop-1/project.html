Workshop project

From a static page to a connected application.

These first three workshops form one learning sequence: publish structured content, explore an API on a map, then listen to real-time messages.

Workshop 01HTML + CSS

Personal site

A responsive set of pages with consistent navigation, deliberate typography, an original illustration, and accessible structure.

Outcome: a clear foundation that can be published as static files.

Workshop 02JavaScript + API

Photo discovery map

A Google Maps interface that requests nearby photo data, manages markers, and reveals contextual details on demand.

Outcome: a browser application driven by external spatial data.

Workshop 03MQTT + live UI

Message viewer

A live feed that subscribes to the CE Lab topic and turns incoming MQTT messages into timestamped, readable cards.

Outcome: an interface that responds safely to real-time events.

Definition of done

Understand it, don’t just run it.

Each stage is backed by tests and browser checks, but the most important review is being able to explain the choices in the source.
